Privacy Policy

Last updated: September 2026 · Applies to Eli6Overlay desktop application and this website.

Short version: Eli6Overlay collects absolutely no data. It does not connect to any server. It does not track usage. Everything stays on your machine.

1. Data We Collect

None. Eli6Overlay does not collect, store, transmit, or share any personal data, usage statistics, crash reports, telemetry, analytics, or any other information about you or your usage.

2. Network Connections

The Eli6Overlay application itself makes no outbound network connections. The browser tabs inside the overlay connect to whatever URLs you navigate to — those connections are subject to the privacy policies of those websites, not ours.

3. Local Storage

Eli6Overlay stores the following data locally on your device only, never transmitted anywhere:

• Your scratchpad notes (saved to localStorage in the app's Electron partition)
• UI preferences: language, opacity, auto-mute setting, hide-on-blank setting

This data never leaves your machine and can be cleared by uninstalling the application.

4. This Website

This GitHub Pages website (eliseyrotar.github.io/Eli6Overlay) is a static HTML page. It uses Google Fonts for typography, which involves a request to Google's servers. No analytics, tracking scripts, cookies, or third-party services beyond Google Fonts are used.

5. Code Signing

Windows release builds are submitted to SignPath Foundation for code signing. This process involves uploading the compiled executable binary to SignPath's servers for signing. No user data is involved — only the application binary.

6. Open Source

Eli6Overlay is fully open source under the MIT License. You can inspect every line of source code at github.com/EliseyRotar/Eli6Overlay to verify these claims.
