The same flag Netflix
uses for DRM.

Windows has a documented API that tells the Desktop Window Manager to exclude a window from every capture path. BitBlt, DWM frame capture, GPU capture, PrintScreen, Win+Shift+S, remote desktop — all of them.

Eli6Overlay calls it on startup. The window renders on your physical display normally. Anything trying to capture it gets a black rectangle or nothing at all.

What it does

9 features, 0 subscriptions
🛡

Anti-Capture

Uses SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE) via setContentProtection(true). Invisible to OBS, Discord, Zoom, Teams, PrintScreen, Win+Shift+S and GPU capture. Same API as Netflix DRM.

🚨

Panic Key

Press Esc — the overlay hides in under 100ms, every tab navigates to about:blank, audio mutes. No trace on screen.

👻

Zero Taskbar

Never in Taskbar or Alt+Tab. Only the tray icon and Ctrl+Shift+G can reveal it.

💾

Soft Close

Closing hides — never quits. Every tab, session and form stays loaded in memory.

🖱

Click-Through

Ctrl+Shift+C makes the overlay transparent to mouse input. Clicks pass through to apps beneath.

🔇

Auto-Mute

Audio mutes the instant the overlay hides. Restores on show. Works across all tabs at once.

🌐

Full Browser

Multi-tab browser, URL/search bar, back/forward/refresh, bookmarks for ChatGPT, Google, Wikipedia.

📝

Scratchpad

Offline notes tab, auto-save to localStorage. Never transmitted anywhere.

🚫

Ad Blocker

Built-in ad and tracker blocker powered by EasyList and uBlock Origin filter lists. On by default, toggle in Settings.
