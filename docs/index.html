Windows has a documented API that tells the Desktop Window Manager to exclude a window from every capture path. BitBlt, DWM frame capture, GPU capture, PrintScreen, Win+Shift+S, remote desktop â€” all of them. The window's pixels simply aren't handed to any of those systems.

Eli6Overlay calls it on startup. The window renders on your physical display normally. Anything trying to capture it gets a black rectangle or nothing at all.
