What it does

Everything you need. Nothing you don't.

A browser overlay built for one job: stay invisible. No bloat, no subscriptions, no tracking.

🛡

Anti-Capture

Uses SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE) — the same Windows API used by Netflix DRM. The overlay is physically rendered on your monitor but completely absent from any recording or capture.

👻

Zero Taskbar Presence

The window never appears in the taskbar or Alt+Tab switcher. The only way to access it is via the system tray icon or the global hotkey.

💾

Soft Close

Closing or hiding the window preserves every open tab, loaded page, login session, and form field in memory. Nothing is lost until you explicitly quit from the tray.

🚨

Panic Key

Press Escape to vanish in under 100ms — the overlay hides, audio mutes, and every tab navigates to about:blank. No trace left on screen.

🖱

Click-Through Mode

Toggle with Win+Shift+C. In click-through mode the overlay is still visible to you but mouse clicks pass directly to applications underneath it.

🔇

Auto-Mute on Hide

Audio mutes the moment the overlay is hidden and restores when you bring it back. Works across all tabs simultaneously.

🌐

Full Browser

Multi-tab browser with URL bar, smart search, back/forward/refresh, and one-click bookmarks for ChatGPT, Google, and Wikipedia.

📝

Private Scratchpad

A dedicated offline notes tab that auto-saves to localStorage. Completely private — never leaves your machine.

⚙️

Opacity & Language

Slide opacity from 10% to 100%. Switch the entire UI between English and Italian instantly — no restart needed.

Under the hood

The same API Netflix uses.

When Eli6Overlay starts, it calls win.setContentProtection(true) in Electron. On Windows this maps directly to the Win32 API call:

SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)

This instructs the Desktop Window Manager to exclude the window's pixels from any capture path — BitBlt, DWM frame capture, GPU-based OBS capture, PrintScreen, Win+Shift+S, remote desktop, all of it.

The same flag is used by Netflix, Disney+, banking apps, and Windows Hello to prevent screen recording of protected content. It is a documented, officially supported Windows API — not a hack.

Microsoft Docs →

// Electron main process const win = new BrowserWindow({ frame: false, transparent: true, alwaysOnTop: true, skipTaskbar: true, }); // Calls SetWindowDisplayAffinity // with WDA_EXCLUDEFROMCAPTURE (0x11) win.setContentProtection(true); // Hide instead of close win.on('close', (e) => { e.preventDefault(); win.hide(); });
