Anti-capture transparent browser overlay for Windows. Hidden from OBS, Discord, Zoom & screenshots — always on top, always invisible.

Features

🛡 Anti-Capture

Uses SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE) via Electron's setContentProtection(true). Invisible to OBS, Discord screen share, Zoom, Teams, and PrintScreen.

👻 Skip Taskbar

Never appears in the Windows Taskbar or Alt+Tab switcher. Accessible only via the system tray icon.

💾 Soft Close

The window hides instead of closing. All tabs, sessions, and form state persist in memory until you quit from the tray.

🖱 Click-Through Mode

Win+Shift+C makes the overlay fully transparent to mouse input — clicks pass through to apps underneath.

🔇 Auto-Mute

Audio mutes automatically on hide and restores on show. Works across all open tabs.

🚨 Panic Key

Press Escape to instantly hide the overlay, mute all audio, and navigate every tab to about:blank.

🌐 Multi-Tab Browser

Full browser with tabs, URL/search bar, back/forward/refresh, and quick bookmarks: ChatGPT, Google, Wikipedia.

📝 Offline Scratchpad

Private notes tab with auto-save to localStorage. Survives app restarts.

🌍 EN / IT Bilingual

Complete English and Italian UI. All labels, tooltips, and menus switch instantly.

How It Works

Eli6Overlay calls win.setContentProtection(true) in Electron, which internally invokes the Windows API SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE) — the same mechanism used by Netflix DRM, documented on Microsoft Docs. The window renders normally on your physical monitor but appears black or entirely absent in any screen recording, capture tool, or remote viewer (OBS, Discord, Zoom, Teams, Win+PrintScreen).
